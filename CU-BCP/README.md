# ขอบเขตความสามารถของระบบฐานข้อมูลแบ่งตามเฟสการพัฒนา #

Phase 1
1.	ออกแบบเว็บไซต์ประชาสัมพันธ์หลักสูตรสำหรับบุคคลทั่วไป และสมาชิก โดยมีเพจหลัก ดังนี้
 
1.1	เกี่ยวกับองค์กร
1.2	แนะนำหลักสูตร 
1.3	ข่าวประกาศ/ข่าวประชาสัมพันธ์
1.4	บริการวิชาการ งานประชุม (ปฏิทินกิจกรรม)
1.5	กรรมการบริหารหลักสูตร และ คณาจารย์ 
1.6	งานวิจัย
1.7	ดาวน์โหลด
1.8	ติดต่อสอบถาม
 
2.	พัฒนาระบบบริหารจัดการเว็บไซต์ (Content Management System) ตามข้อ 1 สำหรับผู้ดูแลระบบ (Admin)
Phase 2
1.	พัฒนาระบบฐานข้อมูลหลักสูตรเภสัชกรประจำบ้าน สำหรับสมาชิกและผู้ดูแลระบบ
1.1.	ข้อมูลประวัติเภสัชกรประจำบ้าน สามารถพิมพ์หรือส่งเอกสารออกเป็น pdf ได้ 
1.2.	ข้อมูลอาจารย์ประจำหลักสูตรฯ
1.3.	ประมวลรายวิชาต่าง ๆ
1.4.	ข้อมูลแหล่งฝึก
1.5.	งานลงทะเบียนต่าง ๆ
1.6.	การยื่นคำร้องต่าง ๆ
1.7.	รายงานผลการศึกษา
1.8.	ระบบการส่งงานของเภสัชกรประจำบ้าน
1.9.	ระบบการแจ้งเตือน admin เมื่อมีการยื่นคำร้องฯ
Phase 3
1.	พัฒนาระบบการจัดการเอกสาร จดหมาย บันทึกข้อความ เอกสารต่างๆที่เกี่ยวข้อง ของหลักสูตร และ ของวิทยาลัยเภสัชบำบัด
1.1.	เอกสารปะหน้านำส่งใบลงทะเบียน 
1.2.	เอกสารปะหน้าการขอส่งสอบในแต่ละประเภท 
1.3.	เอกสารปะหน้าการขอจริยธรรมการวิจัย 
1.4.	เอกสารปะหน้าการขอเข้าเก็บข้อมูลการวิจัย 
1.5.	เอกสารปะหน้าการขอเข้าร่วมประชุมวิชาการ
1.6.	เอกสารคำร้องต่างๆ
2.	พัฒนาระบบรายงานหรือข้อมูลสถิติต่างๆ
3.	พัฒนาระบบการเบิกจ่ายเงินการบริหารจัดการภายในหน่วยงาน
